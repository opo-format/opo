# Contributing

Thank you for helping. The short version:

1. **Find or open an issue** with a goal and acceptance criteria (`docs/workflow.md` §1).
2. **Branch, change one thing, open a pull request** that links the issue. Use Conventional Commit messages.
3. **Make CI green.** It checks formatting, schemas, conformance and licences.
4. **Changing the standard?** Write a proposal (`proposals/`) or a decision record (`decisions/`) first.

Where things live: `docs/architecture.md`. Words we use: `docs/glossary.md`. AI agents: read `AGENTS.md`.

Objects (doors, walls, stairs…) are contributed to `opo-format/library`, the Rust implementation to `opo-format/opo-rs`.
